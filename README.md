This repository contains the end-to-end automation test suite for the **Telnyx** website, built using Cypress.

**Multi-Environment Configuration:** 
  Implemented a scalable multi-config approach. The primary `cypress.config.js` is dedicated to Production, while `cypress.staging.config.js` is set up for the Staging environment.
